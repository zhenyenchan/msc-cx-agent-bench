Grading agent answers on customer feedback analysis tasks

Please read the following guidelines carefully.

An AI agent has been asked questions about customer feedback and has written answers. For each task, you will see a question, an agent's answer and a gold answer — the answer we're treating as the correct one. Please decide how close the agent's answer is to the gold answer by assigning a score from 0 to 5, and leave some comments on why you gave that score.

You will not see the original customer data — you don't need it because you're not working out the right answer yourself. You're only comparing the agent's answer to the gold answer provided.

What every gold answer contains

Every gold answer has the same structure below. Use this as your checklist when comparing:

  • The verdict — the direct answer to the question (yes or no, a top-3 list, the single biggest problem etc.)
  • The numbers — the supporting figures (percentages, counts).
  • The catch — some questions specifically ask for a key point. For example, a gold answer might say whether a difference is big enough to be meaningful ("statistically significant"). Another gold answer might include a warning that one number is based on too few reviews to trust ("sample size is too small"). Not every question has a catch.

Before you start: flag anything unclear (optional)

The gold answers have already been verified, but if a question or gold answer still looks unclear or wrong to you, say why in the comment box. If nothing seems off, just leave it blank and move on to grading.

Grading rules

Use the following rules when grading the agent's answer (score 0 to 5):

  • Always leave a comment. For every score, write 1–2 sentences saying what decided it — see the examples below.
  • Getting the direction right matters most. Saying yes when the answer is no, naming the wrong problem, or putting a ranking in the wrong order is a big mistake, even if the answer reads well.
  • If the agent doesn't include the "catch" when the question asks for it, it can't score higher than 3.
  • If the agent doesn't answer the question, it can't score higher than 2.
  • Complete this yourself. Please don't discuss the tasks with other people or use any AI tools.
  • Grade each task on its own. Don't skip ahead or go back to compare tasks.

The rubric

ScoreWhat it means
5Relevant, accurate, and complete. Right verdict, all key numbers right, the "catch" and all requested parts included, nothing that contradicts the gold answer.
4Relevant and mostly accurate. One non-essential part is wrong or missing, but the recommended actions are correct.
3Relevant and correct direction, but a key number is wrong or missing, or the required "catch" is left out.
2The answer sounds relevant but is inaccurate. Wrong verdict, no supporting numbers or a made-up/contradicting claim.
1Barely relevant. The main answer is wrong or so vague that there is almost nothing you can check.
0Doesn't answer the question asked. Wrong, contradicts itself, off-topic, a refusal, or blank.
